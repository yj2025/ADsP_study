# 이메일 인증과 계정 복구

- 새 회원은 가입 후 이메일 인증 링크를 열고 가입 때 입력한 비밀번호를 확인한 뒤 로그인할 수 있습니다. 인증 링크는 60분 동안 유효합니다. 기존 계정에는 재인증을 강제하지 않습니다.
- 로그인 창에서 **비밀번호를 잊었어요**를 선택하면 재설정 링크를 요청할 수 있습니다. 링크는 30분 동안 유효합니다. 재설정하면 해당 계정의 기존 세션이 모두 종료되며 학습 기록은 유지됩니다.
- 세션 만료는 보호된 요청에서 즉시 감지하며, 로그인 중에는 1분마다 또는 탭에 다시 돌아왔을 때도 확인합니다. 저장하지 못한 기록은 탭을 닫기 전에 같은 계정으로 재로그인하면 다시 저장을 시도합니다.
- 링크는 한 번만 사용할 수 있으며 DB에는 토큰의 해시만 보관합니다. 인증·재설정 링크는 브라우저에서 열면 주소 표시줄에서 제거됩니다.

## 로컬에서 확인하기

기본 로컬 서버에서 가입하거나 재설정을 요청하면 발송 내용이 `data/mail-outbox/`에 JSON 파일로 저장됩니다. 최신 메시지의 `link`를 브라우저에서 열어 진행하세요. 이 모드에서는 실제 이메일을 보내지 않습니다. 다른 로컬 주소를 쓰려면 `.env`에 `MAIL_MODE=local`과 정확한 `APP_ORIGIN`을 지정합니다. 메일 보관함에는 사용할 수 있는 링크가 들어 있으므로 공유하거나 외부에 노출하지 마세요.

## 실제 이메일 발송

`.env.example`을 참고해 `MAIL_MODE=webhook`, `MAIL_WEBHOOK_URL`, `MAIL_WEBHOOK_TOKEN`, HTTPS `APP_ORIGIN`, `COOKIE_SECURE=1`을 설정한 뒤 서버를 재시작합니다. 기존 `.env`가 있다면 필요한 항목만 추가하세요.

서버는 지정된 HTTPS 웹훅에 Bearer 인증을 사용해 `to`, `subject`, `text`, `kind`, `link`가 포함된 JSON을 POST합니다. 웹훅은 `to` 주소로 `subject`와 `text`를 발송하고 성공하면 2xx를 반환해야 합니다. 이메일 서비스에 맞춰 이 요청을 받아 발송하는 웹훅을 연결해야 실제 메일이 전송됩니다. 리다이렉트는 허용하지 않습니다.
