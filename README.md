# ADsP 스터디룸

Node.js 24 이상에서 추가 패키지 설치 없이 실행하는 학습 앱입니다. 
이메일 회원가입·로그인과 SQLite 기반 계정별 학습 기록 저장을 지원합니다.

## 실행

HTTPS 실행, 공개 배포 구성, SQLite 백업·복구는 [배포 가이드](docs/DEPLOY.md)를 참고하세요.

프로젝트 폴더에서 `npm start` 실행 후 http://127.0.0.1:4173 으로 접속합니다. HTML 파일을 직접 열거나 정적 서버로 실행하면 로그인 API를 사용할 수 없습니다.

이메일과 10~128자 비밀번호로 가입하고 로그인할 수 있습니다. 회원가입 시 선택적으로 같은 주소의 브라우저 게스트 학습 기록을 가져올 수 있습니다. 기존 계정 로그인 시에는 서버의 기록을 불러옵니다. 로그아웃하면 게스트 기록으로 돌아갑니다.

회원·학습·세션 정보는 `data/study.sqlite`에 저장되며 Git에서는 제외됩니다. 서버를 재시작해도 유지됩니다. 이 폴더를 보존하고 백업해 주세요. 비밀번호는 무작위 salt를 사용하는 scrypt 해시로, 세션 토큰은 SHA-256 해시로 저장됩니다. 세션 쿠키는 HttpOnly/SameSite=Strict이며 7일 후 만료됩니다. 인증 시도는 IP별 15분당 30회로 제한됩니다.

현재는 로컬 실행용입니다. 기존 Sites 정적 배포에는 이 Node 서버가 실행되지 않습니다. 외부 서비스로 운영하려면 영구 저장 디스크가 있는 Node 호스팅과 HTTPS를 구성하고 `APP_ORIGIN`을 실제 서비스 주소로, `COOKIE_SECURE=1`로 설정해야 합니다. 이메일 인증, 비밀번호 재설정 및 발송 설정은 [계정 관리 가이드](docs/ACCOUNT.md)를 참고하세요.

## 구현 범위

개념과 문제는 SQLite DB에서 불러옵니다. CSV/JSON 추가 방법과 형식은 [콘텐츠 가져오기 가이드](content/README.md)를 참고하세요. 예제 파일은 `content/example.json`, `content/example.csv`입니다.

관리자는 화면에서 파일 업로드 → 대상 과목·단원 선택 → 검증 결과 확인 → 저장을 진행할 수 있습니다. 관리자 지정과 사용 방법은 [관리자 가이드](docs/ADMIN.md)를 참고하세요.

- 데이터와 정보 단원: 정성/정량, 정형/반정형/비정형, DIKW 개념 카드 3개
- 과목·단원 선택, 단원별 학습 위치 복원 및 진도·문제·오답 분리
- 직접 작성한 예상 문제 6개, 답안 제출, 해설 및 관련 개념 이동
- 첫 오답 자동 수집, 정답을 가린 재풀이, 복습 완료 상태
- localStorage에 개념 학습 위치, 완료 상태, 최초 답안, 문제 위치, 오답 복습 상태 저장
- 단원 진도 = (해당 단원의 완료 개념 + 풀이 문제 + 복습 완료 오답) / (해당 단원의 개념 수 + 문제 수 + 최초 오답 수)
- 모바일 대응, 키보드 포커스, 저장 실패 안내, 확인 후 기록 초기화

게스트 기록은 같은 주소·기기·브라우저에만 유지되고, 로그인 기록은 계정별로 서버에 저장됩니다. 서로 다른 탭에서 다른 계정으로 로그인한 경우 저장을 거부해 기록이 섞이는 것을 방지합니다. 최초 정답률은 재풀이로 바뀌지 않습니다. 다른 과목은 구조만 준비되어 있고 콘텐츠는 가져오기 기능으로 추가할 수 있습니다. 모의고사는 아직 구현 범위에 포함되지 않습니다. 외부 폰트를 불러오지 못하면 시스템 글꼴을 사용합니다.

## 확인

`npm test`로 학습 흐름 및 실제 HTTP 인증 통합 테스트를 실행합니다. 인증 테스트는 임시 SQLite DB를 사용하며 회원가입, 중복/잘못된 입력, 로그인 실패, 계정 분리, 서버 재시작, 세션 교체·만료·로그아웃, 교차 출처 요청 차단, 시도 제한을 확인합니다.

단원별 문제 풀이에서는 문제 수와 출제 순서를 선택할 수 있습니다. 단원마다 최근 세트를 저장하고, 완료한 세트는 같은 문제로 다시 풀거나 새 세트를 만들 수 있습니다. 세트 결과는 첫 풀이 진도 및 오답 노트와 별도로 계산합니다.

오답 노트에는 첫 풀이와 재풀이에서 틀린 문제가 모입니다. 문제마다 오답 이유를 메모할 수 있고, 두 번 이상 틀리면 반복 오답으로 표시합니다. 복습 대기 중인 문제를 오답 횟수, 최근 오답 순으로 추천합니다. 복습에서 맞히면 완료되며 이후 다시 틀리면 복습 대기로 돌아갑니다.

모의고사에서는 공개 문제 중 최대 50개와 제한 시간(1~90분)을 정해 응시합니다. 문제를 제공하는 과목에서 번갈아 무작위로 출제하며, 새로고침 후에도 제한 시간과 응답이 유지됩니다. 시간이 끝나면 앱에서 자동 제출하고, 과목별 결과와 해설을 표시합니다. 응답해서 틀린 문항은 오답 노트에 모이며 미응답은 결과에서 따로 표시합니다.
